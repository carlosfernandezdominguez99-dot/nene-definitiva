Esta web no tiene formularios propios ni registro de usuarios. Solo tratamos datos personales cuando tú nos los facilitas:

  • Datos técnicos de navegación: el servidor que aloja la web registra de forma automática la dirección IP y datos técnicos de la visita para servir la página y por seguridad.
